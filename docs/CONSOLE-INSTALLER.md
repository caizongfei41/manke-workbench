# 漫客工作台 · 控制台安装包

一个 25 MB 的 exe，装完就能用它下载、校验、部署整套工作台。

---

## 这是什么

控制台本身不含模型，也不含 ComfyUI。它装的是**部署工具**：

| 装进什么 | 作用 |
|---|---|
| `launcher/` | 控制台界面：启停服务、环境自检、一键部署 |
| `scripts/` | 部署脚本、环境检查、依赖审计 |
| `node/` | 便携 Node 24 —— 目标机器不用自己装 |
| `node/7z.exe` | 便携 7-Zip —— 解压分卷用 |
| `docs/` | 依赖清单 |

**为什么自带 Node 和 7-Zip**：控制台的部署脚本要靠 Node 运行，分卷要靠 7-Zip 解压。让用户先装这两个，等于把“一键部署”的门槛又抬回去。两个加起来约 92 MB，压缩后 25 MB，值得。

---

## 安装

1. 双击 `漫客工作台控制台-Setup.exe`
2. 选安装位置（默认 `%LOCALAPPDATA%\Programs\漫客工作台`）
3. 点「安装」，约 1-2 分钟
4. 勾选「立即打开控制台」

**不要装到 `C:\Program Files`** —— 需要管理员权限，安装会失败。向导会提前拦下并说明原因。

### 静默安装

```powershell
漫客工作台控制台-Setup.exe /S /D=D:\漫客工作台
```

## 装完做什么

控制台只负责部署，工作台本体和模型要从网盘下载。

```
1. 从网盘下载 7 个分卷（210.7 GB）
2. 全部放进安装目录的 deploy\ 里
3. 打开控制台
4. 点「检查部署包」→ 应显示「7 个 · 210.7 GB —— 完整」
5. 点「一键部署」→ 选一个空间足够的盘
6. 等 20-40 分钟
```

解压完成后会得到：

```
<你选的盘>\
└── manke\
    ├── ComfyUI\       可以直接运行（含 Python、模型、节点）
    └── workbench\     工作台源码
```

### 磁盘要求

| 阶段 | 占用 |
|---|---|
| 控制台 | 约 100 MB |
| 7 个分卷 | 210.7 GB |
| 解压后 | 211 GB |
| **总峰值** | **约 422 GB** |

解压完可以删掉分卷，省 210.7 GB。

## 控制台上的按钮

| 按钮 | 作用 |
|---|---|
| **一键部署** | 检查分卷 → 选盘 → 解压 |
| **检查部署包** | 只看分卷齐不齐，不动文件 |
| **ComfyUI 位置** | 指定 ComfyUI 在哪（换机器必用） |
| **全部启动 / 全部停止** | 同时开关 ComfyUI 和工作台 |
| **检查**（环境自检） | 12 项检查，告诉你缺什么 |

### ComfyUI 位置

如果机器上已经有 ComfyUI，点这个按钮指定位置，控制台会写进 `data/comfyui.config.json`，启动和工作台服务端都读它。

**不指定的话**，自检会明确报「还没指定 ComfyUI 在哪」，而不是偷偷去猜某个盘。

## 卸载

三种方式，效果一样：

1. **设置 → 应用 → 「漫客工作台 · 服务控制台」→ 卸载**
2. 双击安装目录里的 `卸载.vbs`
3. 命令行跑 `uninstall.cmd`

### 会删什么

- 控制台程序、Node、7-Zip
- 桌面和开始菜单快捷方式
- 注册表卸载项

### 不会删什么

| 内容 | 为什么保留 |
|---|---|
| `deploy\` 里的分卷 | 那是 200 GB 数据 |
| ComfyUI 安装目录 | 模型和节点在里面 |
| 工作台项目目录 | `.output`、`node_modules` |
| 计划任务 `BD-ComfyUI` / `BD-Workbench` | 那是运行环境 |

## 常见问题

**Q: 装的时候报「需要 7-Zip」**
控制台自带了 `node/7z.exe`，正常不会走到这条路。如果出现，说明安装包不完整，重下。

**Q: 一键部署点了没反应**
先点「检查部署包」看分卷状态。分卷不全时点一键部署会先让你选目录，不会再静默失败。

**Q: 提示「目标盘空间不足」**
解压要 211 GB。选盘窗口会列出每个盘的可用空间和差多少 GB。

**Q: 解压完 ComfyUI 起不来，报 `ImportError: cannot import name 'models'`**
说明 `torchvision\models` 目录缺失，是打包时用递归排除误删的旧问题。当前的包已修复（7.0 GB 版本），重新解压。

**Q: 设置里点卸载没反应**
旧版 `卸载.cmd` 有中文路径解码 bug。当前版本已改用 `.vbs` 入口，重新安装即可。
